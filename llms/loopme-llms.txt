# LoopMe

> LoopMe is a global brand-performance advertising platform that uses AI to bring brands into mobile and CTV apps, delivering higher campaign performance for advertisers and premium yield for publishers. Its developer surface consists of a REST Reporting API (publisher and advertiser statistics), a server-to-server (S2S) ad request API, first-party United SDKs for Android and iOS, CDN-hosted web ad tags, and a Prebid.js header-bidding adapter. LoopMe publishes no OpenAPI, no /llms.txt, no /.well-known documents and no MCP or A2A surface; the specifications below are API Evangelist reconstructions of the published documentation.

## APIs

- [Reporting API](https://wiki.loopme.cool/publishers/reporting-api): Publisher (app/site) and advertiser (campaign/line item/creative) statistics. GET only, `api_auth_token` query parameter, JSON, USD, UTC. Base `https://reports.loopme.com/api/v1`.
- [S2S Ad Request API](https://wiki.loopme.cool/publishers/integrations/s2s): Server-to-server ad request returning an MRAID ad payload or an empty ads array. Identified by `appId`, no token. Base `https://loopme.me/api/s2s`.

## Semantics

- [Authentication](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/authentication/loopme-authentication.yml): 16-character `api_auth_token` query parameter, enabled per account in the dashboard.
- [Conventions](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/conventions/loopme-conventions.yml): No pagination, no idempotency key, UTC dates, USD currency.
- [Error codes](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/errors/loopme-error-codes.yml): The eleven published Reporting API codes and the `{ "errors": { code: description } }` envelope.
- [Rate limits](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/rate-limits/loopme-rate-limits.yml): None documented.
- [Plans and pricing](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/plans/loopme-plans-pricing.yml): None published; commercial terms are set per account.
- [Data model](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/data-model/loopme-data-model.yml): App, Campaign, LineItem, Creative, ReportPoint.
- [Conformance](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/conformance/loopme-conformance.yml): ads.txt, TAG, IAB TCF v2, US Privacy, VAST/VPAID, MRAID, SKAdNetwork, Prebid.
- [Sandbox](https://raw.githubusercontent.com/api-evangelist/loopme/refs/heads/main/sandbox/loopme-sandbox.yml): No API sandbox; device-side tester apps only.
